# Shadow hands learn to play the piano

Write-up of a from-scratch RL project: two MuJoCo Shadow Hands on rails learning
to play Nettspend's "we not like you" on an 88-key piano with PPO, no
demonstrations and no pretrained weights. Best run scores F1 0.803.

All clips are rendered from the trained v15 checkpoint rolled out in MuJoCo.
